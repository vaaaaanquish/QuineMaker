# QuineMaker

画像をアップロードすると、その形に整形されたQuine(実行するとソース自身と同じ文字列を出力するプログラム)を生成します。

動画をアップロードすると、循環Quineを生成します。フレームごとに整形されたプログラムの連鎖で、各プログラムを実行すると次のフレームの形をしたプログラムが出力され、最終フレームの次は元のプログラムに戻ります(N回実行で元に戻る周期NのQuine)。

各プログラムは「先頭行＋データ行(全フレームのレイアウトをdeflate圧縮したもの)＋絵＋起動行」の矩形で、**絵が出力の末尾**に来るため、そのまま流すだけでターミナルに絵が残ります。フレーム数の上限はありません(数分の動画もフル再生できます)。

```sh
# 生成した s.py を再生する例
while :; do python3 s.py > n.py && mv n.py s.py; clear; cat s.py; sleep 0.2; done
```

## 開発

```sh
npm test            # 生成器のユニットテスト（python3 が必要）
npm run serve       # http://localhost:8000 でローカル確認
```
